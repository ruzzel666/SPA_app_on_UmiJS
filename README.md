# SPA_app_on_UmiJS

Студенческая работа, представленная в виде SPA веб-приложения на основе фреймворка UmiJS и UI-библиотеки Ant Design. 

**Автор:** Зайцев Георгий, магистр 1 курса направления 09.04.02 "Информационные системы и технологии в металлургии".

## 🛠 Технологический стек

Проект построен на современных инструментах frontend-разработки:

- **[UmiJS (Max)](https://umijs.org/)** — Масштабируемый Enterprise React фреймворк с встроенным роутингом, поддержкой сборки и множеством плагинов.
- **[React](https://reactjs.org/)** — Основная библиотека для построения пользовательских интерфейсов.
- **[Ant Design](https://ant.design/)** — Мощная библиотека UI-компонентов корпоративного уровня, используемая для стилизации и верстки.
- **[@ant-design/charts](https://charts.ant.design/)** — Построение аналитических графиков и диаграмм.
- **[Apollo Client](https://www.apollographql.com/docs/react/) & GraphQL** — Клиент для управления состоянием и взаимодействия с сервером через GraphQL API.
- **[XLSX](https://github.com/SheetJS/sheetjs)** — Библиотека для генерации, чтения и экспорта данных в формате Excel.
- **TypeScript** — Строгая статическая типизация кода.
- **Docker & Docker Compose** — Контейнеризация приложения и развертывание с помощью Nginx.

---

## 🏗 Архитектура и основной функционал

Клиентское приложение взаимодействует с отдельным сервером на базе ASP.NET Core 8.0 (`GraphQLShop`), который предоставляет GraphQL API. 

**Ключевые возможности проекта:**
* Просмотр и управление списком товаров (чтение, добавление, удаление, редактирование).
* Аутентификация пользователей (JWT) с перенаправлениями и встроенной обработкой CORS на уровне Nginx и прокси для среды разработки.
* Обработка ошибок сети и авторизации через Apollo Error Link.
* Выгрузка аналитических данных или таблиц в Excel.
* Наличие различных роутов (информационные страницы, графики продукции, обратная связь, документация и авторизация).
* Умная система роутинга UmiJS (с хэшированием файлов сборки для избежания проблем с кэшом).

## 🚀 Установка и запуск (Разработка)

### Предварительные требования
Для локальной разработки вам понадобится **Node.js** (рекомендуется версия 18+) и менеджер пакетов `npm`.

1. Клонируйте репозиторий:
   ```bash
   git clone <URL_репозитория>
   cd SPA_app_on_UmiJS
   ```
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Запустите dev-сервер:
   ```bash
   npm run dev
   ```
После этого проект будет доступен по адресу: http://localhost:8000. \
*Примечание: в режиме разработки API запросы проксируются на `http://localhost:7000`, чтобы избежать CORS (настроено в `.umirc.ts`).*

## 🐳 Развертывание в Docker (Production)

Проект полностью готов для production-развертывания с использованием Docker Compose и настроенного локально Nginx. 

В развертывании приложение помещается в контейнер, где статические файлы `dist` отдаются быстрым сервером Nginx. Запросы `/graphql` тоже обрабатываются с помощью Nginx во внутреннюю сеть Docker (к API контейнеру), чтобы предотвратить блокировку запросов.

1. Убедитесь, что backend-сервер настроен и его Docker Compose уже запущен (сеть `graphql-spa-network` должна существовать).
2. Запустите сборку и создание контейнеров одной командой:
   ```bash
   docker-compose up -d --build
   ```

Теперь Frontend-приложение будет доступно на хосте по порту: **http://localhost:3000**

## 📜 Доступные NPM Скрипты

* `npm run dev` — запуск локального development-сервера.
* `npm run build` — компиляция проекта для Production. Создаст минифицированные файлы в папке `dist/`.
* `npm run postinstall` — установка базовых вспомогательных типов Umi для TypeScript.
* `npm start` — алиас на запуск `dev`.

## 📄 Структура проекта
* **`/src`** — Основной исходный код React компонент, сервисов и страниц.
* **`src/AppProvider.tsx`** — Конфигурация Apollo Client, настройки GraphQL, кеширования и токенов.
* **`.umirc.ts`** — Конфигурация приложения для UmiJS (роутинг, настройки сборки, dev-proxy).
* **`Dockerfile`** — Инструкции для многоэтапной сборки Frontend-приложения в изолированном образе (Node.js Builder -> Nginx).
* **`docker-compose.yml`** — Инфраструктурный файл для быстрого запуска вместе с backend'ом.
* **`nginx.conf`** — Конфигурация production-сервера Nginx (роутинг SPA, прокси API-запросов `/graphql`, кэширование статики).
